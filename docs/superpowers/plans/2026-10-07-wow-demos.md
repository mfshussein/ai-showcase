# Wow Demos (batch 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Five recorded demos (read-my-dashboard, document-to-json, glossary-translation, enquiry-to-crm, night-watchman) plus the machinery they need.

**Architecture:** Each demo is `demos/<slug>/{manifest.ts, run.ts, run.test.ts, fixtures/, golden.json}` yielding `RunEventInput`s. Deterministic logic lives in `lib/harness/*` with tests written first. New: three panel kinds (counter, timeline, email), image grid and json field rows, `Llm.tools()`, `lib/notify.ts` (Resend email + optional Slack/Teams webhook), `scripts/make-images.mts`.

**Tech Stack:** Next.js 16, React 19, TypeScript, zod 4, vitest, Playwright, openai SDK (OpenRouter, Qwen 3.8).

**Spec:** `docs/superpowers/specs/2026-10-07-wow-demos-design.md`

## Global Constraints

- Fixtures synthetic, fictional, Qatar-flavoured (QAR, Doha/Lusail, Arabic+English). No real companies or people. ID images carry SPECIMEN.
- No emoji in prompts, fixtures or outputs.
- `npm test`, `npx tsc --noEmit`, `npx eslint .` clean after every task.
- Register each demo in `demos/registry.ts`, `demos/runners.ts`, `scripts/record.mts`; golden in `demos/goldens.ts`; status `ready` only after recording.
- Never print, log or put in events any API key or webhook URL.
- Each act fits one projected screen; verdict lands in act 4.

## Review Focus

1. Model returns an anomaly box outside every tile, or a malformed box: callout is dropped, run continues (regions test).
2. Model calls an unknown tool or passes invalid JSON args: loop returns `{ error }` as the tool result and continues; never throws (tools test).
3. Model loops on tool calls forever: stops at `maxSteps` and yields a final step (tools test).
4. Glossary term appears with different case or extra spaces, or as part of a longer word: case/space-insensitive match, word-boundary respected (glossary test).
5. Resend unconfigured, Resend returns 4xx, or webhook fails: run continues, `{ sent:false, reason }` without secrets, evidence-only control event (notify + runner tests).
